# Code of Conduct

Participation in NEXAH ORION follows the canonical
[NEXAH Code of Conduct](https://github.com/Scarabaeus1031/NEXAH/blob/main/CODE_OF_CONDUCT.md).

That document governs community conduct. ORION's `CONTRIBUTING.md` separately
defines repository ownership, architectural review and verification
requirements. Referencing the canonical policy does not duplicate its
authority.
