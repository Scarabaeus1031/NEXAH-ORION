# Schemas

Reserved for versioned ORION-owned public contracts.

No schemas are approved in Phase 1. A schema may be added only after:

1. its repository and contract owner are confirmed;
2. an ADR defines its authority and compatibility surface;
3. producer and consumers are named;
4. versioning and migration behavior are documented.

Existing Core types such as `OrientationState`, `OrientationReport`, `Evidence`, and `SourceBatch` remain owned by the frozen NEXAH Core and are not copied here.
