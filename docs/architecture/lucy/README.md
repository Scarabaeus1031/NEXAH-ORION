# LUCY Concept Exploration

- Status: Phase-7A-Concept-Freeze
- Authority: nicht normativ; keine Änderung der ORION-v1-Baseline
- Repository-Version: `0.3.0-dev.0`

LUCY untersucht die menschliche Rolle von Reflexion neben der eingefrorenen
ORION-Architektur. Diese Dokumente definieren weder Software noch einen neuen
System-Layer. Sie fragen zuerst, warum Reflexion für Menschen wichtig ist und
wo ihre Grenze zu Reasoning, Sprache und Entscheidung liegt.

## Dokumente

| Dokument | Zweck |
|---|---|
| [`LUCY_CONCEPT.md`](LUCY_CONCEPT.md) | erstes vollständiges Concept Document |

| [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md) | bewusst ungeklärte Fragen |
| [`FUTURE_RESEARCH.md`](FUTURE_RESEARCH.md) | mögliche menschenbezogene Forschungsrichtungen |

Die Dokumente sind Exploration, keine Architecture Plate, kein ADR und keine
Implementierungsfreigabe. Wird aus einer späteren Erkenntnis eine normative
Architekturänderung, beginnt dafür ein eigener Review gemäß ADR-0008.

Phase 7A bestätigt die Konsistenz der Sammlung. Der Concept Freeze stabilisiert
ihre Bedeutung, fügt LUCY aber nicht zur ORION Architecture Baseline hinzu.
