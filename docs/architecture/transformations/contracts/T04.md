## Transformation

- **Purpose:** encode documented categorical inputs into declared Scarabaeus state fields without collapsing source lineage.
- **Conceptual operator:** Phase-3B placeholder `x₀=E(c₁,…,cₙ)`; encoding `E` is `unknown`.
- **Required parameters:** category-to-state crosswalk, target field IDs, encoding type, scale/units, normalization, missing-category policy, merge role.
- **Optional parameters:** documented weights, uncertainty propagation, display labels, nonsemantic layout hints.
- **Expected output:** field-level Engine contribution with category/entity trace-back; unmapped values remain explicit.
- **Known limitations:** Scarabaeus state vector and category mapping are undocumented; no execution is allowed.

## Preserved Invariants

- **Identity:** entity and categorical source identity.
- **Provenance:** taxonomy, crosswalk, source representation, encoding profile, and merge role.
- **Orientation Object ID:** unchanged and equal to the T05 merge input.
- **Source references:** category, entity, and source representation IDs retained.
- **Epoch:** preserved when present; no epoch may be introduced.
- **Known constants:** only crosswalk-defined scales/units; none are currently registered.

## Lossiness

- **Information preserved:** mapped category/entity references and declared field values.
- **Information hidden:** taxonomy hierarchy and curator context retained by reference.
- **Information aggregated:** multiple categories encoded into one state field where explicitly declared.
- **Information discarded:** none authorized before the encoding is documented.
- **Unknown:** field-level lossiness and reversibility because `E` and the state profile are unknown.

## Evidence

- **Current evidence level:** `E0`; no category-to-state assignment is documented.
- **Missing evidence:** Scarabaeus state schema, field semantics, crosswalk, units, scaling, merge semantics.
- **Required datasets:** versioned category-to-state fixtures with entity/category IDs, expected target fields, units, scale, missing values, and T05 merge references.
- **Open questions:** Which categories map to which fields? Is the mapping discrete, weighted, or contextual?

## Validation

- **Input validation:** source version, taxonomy/crosswalk references, canonical IDs, units, Orientation Object ID, provenance.
- **Output validation:** known target field IDs, encoding version, scale/units, merge role, source trace-back.
- **Invariant checks:** Orientation Object ID equality, entity/category references, provenance, epoch non-invention, T05 merge compatibility.
- **Failure conditions:** missing state schema/crosswalk, hidden normalization, unknown units, source collapse, incompatible merge identity, or execution while `E` is unknown.
