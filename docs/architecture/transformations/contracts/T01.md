# T01 — Reality → Observation

| Field | Declaration |
| --- | --- |
| Transition ID | `T01` |
| Name | Reality to Observation |
| Source Representation | Reality |
| Target Representation | Observation |
| Contract Version | `0.1-draft` |
| Status | `draft`; documentation only |
| Evidence Level | `E1` |
| Operator Status | `unknown` |
| Invertibility | `no` |

## Input Contract

| Field | Requirement |
| --- | --- |
| Required source object | Referenced event or state available to an observer; completeness is not asserted |
| Mandatory metadata | source reference where available, observer ID, timestamp, time basis, instrument/observation profile, scope, sampling rule |
| Coordinate system | Observer-, time-, instrument-, and measurement-coordinate profile; exact profile `unknown` |
| Units | Required for every measured field; otherwise explicitly `unknown` |
| Epoch | Observation timestamp and time basis required; astronomical epoch `not applicable` unless the source declares one |
| Representation version | Required source-reference version where available; no Reality representation version is registered |

## Output Contract

| Field | Requirement |
| --- | --- |
| Produced representation | Immutable Observation representation |
| Required metadata | representation ID, Orientation Object reference where assignable, source reference, observer, timestamp, instrument profile, measured variable, unit, uncertainty status, contract ID/version |
| Coordinate profile | Declared observation profile matching the measured fields |
| Renderer compatibility | Any provider-independent renderer supporting `T01@0.1-draft` and the declared observation profile |
| Version | Target representation version must be assigned by a future renderer; currently `unknown` |

## Transformation

- **Purpose:** bind an observation to an explicit source, observer, time, scope, and instrument context.
- **Conceptual operator:** general measurement model `y=H(x)+ε` from Phase 3B; the actual operator `H` is `unknown`.
- **Required parameters:** observer, instrument profile, units, timestamp/time basis, scope, sampling rule.
- **Optional parameters:** uncertainty profile, environmental conditions, calibration reference, separated human annotation.
- **Expected output:** one provenance-bound Observation; unobserved fields remain absent or `unknown`.
- **Known limitations:** it cannot represent the complete Reality state or recover anything outside the observation window.

## Preserved Invariants

- **Identity:** available source identity only; full Reality identity is not claimed.
- **Provenance:** observer, instrument, time, scope, source reference, and contract version.
- **Orientation Object ID:** preserved when one already exists; otherwise assignment policy is `unknown`.
- **Source references:** retained without replacement.
- **Epoch:** timestamp/time basis preserved; other epoch semantics are conditional.
- **Known constants:** units and calibration constants only when explicitly supplied.

## Lossiness

- **Information preserved:** observed values, declared units, time, observer, scope, and available source reference.
- **Information hidden:** source details outside the selected observation view but reachable through the source reference.
- **Information aggregated:** samples when the declared observation profile aggregates them.
- **Information discarded:** unobserved degrees of freedom and content outside the observation window.
- **Unknown:** uncertainty and source completeness when no corresponding profile exists.

## Evidence

- **Current evidence level:** `E1`; Observe Before Naming is stable, but no executable Observation Contract exists.
- **Missing evidence:** authoritative observation schema, source-identity policy, unit and uncertainty profiles.
- **Required datasets:** versioned observation fixtures containing source references, timestamps, units, scope, and uncertainty status.
- **Open questions:** What is the minimum Reality source reference? Where does observation end and interpretation begin?

## Validation

- **Input validation:** require observer, timestamp/time basis, instrument profile, scope, sampling rule, and units or explicit `unknown`.
- **Output validation:** require immutable observation metadata and separation of measured value from annotation.
- **Invariant checks:** source-reference preservation, timestamp/unit conformance, provenance completeness, no inferred fields.
- **Failure conditions:** missing mandatory metadata, hidden defaults, undeclared units, inferred source fields, or any attempt to execute while the operator is `unknown`.
