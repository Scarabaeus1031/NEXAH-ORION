## Transformation

- **Purpose:** expose a selected path on the Möbius representation as an ordered planar curve.
- **Conceptual operator:** Phase-3B placeholder `γ(t)=h(q(u(t),v(t)))`; observation map `h` is `unknown`.
- **Required parameters:** selected path, chart, seam handling, observation map, output axes, phase origin, parameter interval.
- **Optional parameters:** display-only embedding, sampling density, label profile.
- **Expected output:** ordered planar points with source-point and seam trace-back; crossings do not imply source neighborhood.
- **Known limitations:** no canonical Möbius-to-Lissajous operator or axis mapping exists.

## Preserved Invariants

- **Identity:** selected path identity.
- **Provenance:** source quotient, chart, seam, observation map, and merge role.
- **Orientation Object ID:** unchanged and compatible with a T09 merge input.
- **Source references:** path points and landmarks retained.
- **Epoch:** preserved by reference when present; not derived.
- **Known constants:** none registered; future chart and map constants must be explicit.

## Lossiness

- **Information preserved:** source path order, selected landmarks, and trace-back.
- **Information hidden:** surface coordinates, seam context, and non-orientability when only the curve is displayed.
- **Information aggregated:** distinct surface points mapped to one planar point under a future noninjective map.
- **Information discarded:** surface topology from the target curve alone.
- **Unknown:** continuity, metric distortion, and further losses because `h` is unknown.

## Evidence

- **Current evidence level:** `E0`; no canonical Möbius-to-Lissajous mapping is documented.
- **Missing evidence:** observation map, axis mapping, chart/seam behavior, sampling, landmark crosswalk, merge role with T09.
- **Required datasets:** versioned Möbius path fixtures with chart/seam coordinates, ordered landmarks, expected planar points, and explicit T09 merge references.
- **Open questions:** Which Möbius property determines each Lissajous axis? Is T08 actually part of the Lissajous merge?

## Validation

- **Input validation:** source/path versions, explicit chart and seam, ordered path, complete provenance, observation-map availability.
- **Output validation:** deterministic point order, axes/profile, source-point trace-back, seam annotations, crossing semantics, merge references.
- **Invariant checks:** Orientation Object ID, path order, landmark/source references, provenance, and no false neighborhood at crossings.
- **Failure conditions:** missing `h`, inferred axes, hidden seam, source-order loss, false crossing adjacency, incompatible T09 merge identity, or any execution while operator status is `unknown`.
