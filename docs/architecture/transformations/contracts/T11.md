## Transformation

- **Purpose:** present ordered curve points as directions in a declared stellar/spherical frame.
- **Conceptual operator:** `unknown`; inverse stereographic projection appears only as a Phase-3B candidate and is not established as the actual operator.
- **Required parameters:** documented projection family/operator, source and target frames, center/pole, scale/orientation, point sampling/crosswalk, singularity policy.
- **Optional parameters:** display clipping, landmark labels, camera parameters with no semantic effect.
- **Expected output:** spherical coordinates with complete source-point, frame, projection, and clipping provenance.
- **Known limitations:** projection family and stellar-landmark meaning are undocumented; no conformality or invertibility claim is permitted.

## Preserved Invariants

- **Identity:** curve-point identity and order where the future operator supports it.
- **Provenance:** source curve, point crosswalk, projection/frame profile, clipping, and contract version.
- **Orientation Object ID:** unchanged.
- **Source references:** curve and point IDs retained.
- **Epoch:** source epoch preserved when present; output frame epoch must be explicit and not inferred.
- **Known constants:** projection/frame constants only when documented; none are currently registered.

## Lossiness

- **Information preserved:** point identity/order and source trace-back; additional preservation depends on the unknown operator.
- **Information hidden:** planar axes, curve metric, and crossings when only the stellar view is displayed.
- **Information aggregated:** points only if the future sampling or landmark rule explicitly groups them.
- **Information discarded:** clipped points and planar metric under a declared noninvertible projection.
- **Unknown:** metric, angular, neighborhood, and invertibility losses because the operator is unknown.

## Evidence

- **Current evidence level:** `E0`; the named representations exist, but their connecting projection is not documented.
- **Missing evidence:** projection formula, coordinate frames, axis mapping, pole/center, units, epoch, point-to-landmark crosswalk.
- **Required datasets:** versioned curve-point fixtures paired with expected spherical coordinates, frame/epoch, singularity cases, clipping status, and landmark references.
- **Open questions:** Are output points stars, symbolic markers, or generic spherical coordinates? Is stereographic projection actually used?

## Validation

- **Input validation:** valid curve/point identity and version, ordered points, axes/units, provenance, projection availability.
- **Output validation:** named frame, coordinate conventions/units, projection version, epoch status, source-point trace-back, clipping/singularity declarations.
- **Invariant checks:** Orientation Object ID, point order where declared, source references, provenance, epoch non-invention.
- **Failure conditions:** unknown projection, implicit frame/pole/units, inferred stellar identity, unreported clipping/singularity, or unsupported invertibility claims.
