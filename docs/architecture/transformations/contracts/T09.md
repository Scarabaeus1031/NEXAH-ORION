## Transformation

- **Purpose:** reveal a selected frequency ratio and relative phase as an ordered planar curve.
- **Conceptual operator:** Phase-3B candidate `x=A sin(mt+δ)`, `y=B sin(nt)`.
- **Required parameters:** component IDs, `A`, `B`, `m`, `n`, `δ`, parameter interval, sampling density, phase convention.
- **Optional parameters:** axis/component labels, display scale, closure annotation tolerance.
- **Expected output:** deterministic curve samples retaining component, ratio, phase, and source provenance.
- **Known limitations:** concrete components, parameter values, phase convention, and relation to T08 are absent.

## Preserved Invariants

- **Identity:** selected component-pair identity.
- **Provenance:** source spectrum, component selection, parameter set, sampling profile, and merge role.
- **Orientation Object ID:** unchanged and compatible with a T08 merge input.
- **Source references:** both component IDs and source representation retained.
- **Epoch:** preserved by reference when supplied; otherwise not recoverable.
- **Known constants:** only explicitly supplied ratios, amplitudes, and phase conventions; no values registered by Phase 3C.

## Lossiness

- **Information preserved:** selected ratio, relative phase, component order, amplitudes, and source trace-back.
- **Information hidden:** unselected spectrum and absolute epoch.
- **Information aggregated:** two selected components into one planar curve.
- **Information discarded:** all unselected components from the target curve view.
- **Unknown:** equivalence among parameterizations and merge semantics with T08.

## Evidence

- **Current evidence level:** `E1`; the equations are a strong candidate, but values and source axes are missing.
- **Missing evidence:** component-selection rule, parameter values, phase/axis conventions, interval, sampling profile, T08 merge semantics.
- **Required datasets:** versioned frequency-component fixtures with units, ratios, phase, expected ordered curve samples, equivalence cases, and T08 merge references.
- **Open questions:** Which axes/components are selected? Is the curve closed or bounded by an observation interval?

## Validation

- **Input validation:** exactly declared components, compatible units/conventions, complete parameters, representation version, provenance.
- **Output validation:** deterministic samples/order, parameter metadata, source trace-back, coordinate profile, merge references.
- **Invariant checks:** Orientation Object ID, ratio, relative phase, component order, source references, provenance.
- **Failure conditions:** incomplete parameters, hidden defaults, incompatible units/phase conventions, inferred components, incompatible T08 merge identity, or execution before the candidate is approved.
