# Proof of Architecture Experiments

> **Status:** Informative navigation only

These are three related, bounded experiments along one frozen `COMPARE`
lineage. They are not one uninterrupted validation chain, a certification
system, or evidence of general OLS, Processor, Representation, Runtime, or
domain validity.
