# ORION Roadmap Index

This directory separates capability direction, vertical-slice boundaries, and
bounded engineering plans.

## Canonical reading order

1. [`ORION_CAPABILITY_ROADMAP.md`](ORION_CAPABILITY_ROADMAP.md) — capability
   sequence from the proven structural foundation toward later ORION work.
2. [`ORION_VERTICAL_SLICES.md`](ORION_VERTICAL_SLICES.md) — canonical
   executable boundaries and STOP conditions for each vertical slice.
3. [`SLICE_IV_ENGINEERING_PLAN.md`](SLICE_IV_ENGINEERING_PLAN.md) — canonical
   implementation order for the approved Expression Architecture.
4. [`SLICE_IV_WORK_PACKAGES.md`](SLICE_IV_WORK_PACKAGES.md) — normative
   WP26–WP30 responsibilities, dependencies, inputs, outputs, and STOPs.
5. [`SLICE_IV_CERTIFICATION_PATH.md`](SLICE_IV_CERTIFICATION_PATH.md) —
   Expression Contract, Construction, External Conformance, Expression
   Certification, and final Slice IV gates.
